## Descripción

Esta página nos sirve para adentrarnos un poco al mundo de la Graficación, repasaremos cinco momentos históricos que marcaron el camino de este arte, visualizaremos una aplicación real a la que estamos acostumbrados a usar, a así como analizaremos algunas cuestiones matemáticas convirtiendo valores RGB a HSV para analizar estos datos, un algoritmo para dejar de lado los cálculos a mano y un glosario con algunas palabras que pueden ayudarnos a adentrarnos a este mundo, así como las conclusiones que puedo compartir.

## Estructura

El proyecto contiene las secciones de:

img/ (donde se encuentran los recursos utilizados9

index.html (archivo HTML para la creación de la página)

style.css (archivo CSS con líneas para dar el estilo bonito)
